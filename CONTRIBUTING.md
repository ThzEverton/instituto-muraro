# Contribuição

Equipe ETH Tecnologia, desenvolvimento privado. Sempre abrir issue e PR para develop. Prefixos de commits: feat:, fix:, refactor:, test:, docs:, chore:, security:.

Checklist: sem dados reais/credenciais; TypeScript/build/testes passam; requisitos de autorização clínica verificados; migrations/Swagger sincronizados se houver API; print de tela apenas com dados sintéticos; docs/ADR atualizados.
